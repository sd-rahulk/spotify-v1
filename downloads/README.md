# Resonant for Android

[Download the signed release APK](https://raw.githubusercontent.com/sd-rahulk/spotify-v1/main/downloads/resonant-release.apk)

This release targets arm64 Android phones and bundles the app for standalone installation. Open the APK on your phone and follow Android's installation prompt. To use your cloud library, open **Settings**, enter the HTTPS API URL, and enter the one-time pairing code from the web dashboard.

If the debug APK is already installed, Android treats it as a different signer. Back up any files you need from that installation before uninstalling it to install this release.
